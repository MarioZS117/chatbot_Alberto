# sendpulse-rest-api

A simple SendPulse REST client library and example for Python.

## Install using pipy

```sh
pip install pysendpulse

pip install requests

pip install setuptools


#  descargar este principalmente

 pip install python-telegram-bot==22.5

 pip install psycopg2

 pip install fpdf

#Corre Ollama

Start-Process powershell -ArgumentList "-NoExit -Command ollama serve"

#intalación de IA

pip install ollama

#En caso de que se requiera
#python -m pip install "httpx==0.23.3"

```
